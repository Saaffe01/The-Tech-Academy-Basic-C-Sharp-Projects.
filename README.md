# C# and .NET Course Projects

This repository contains the C# assignments I completed during The Tech Academy C# and .NET course. These projects cover console application fundamentals, control flow, arrays, exception handling, methods, classes, inheritance, interfaces, polymorphism, operator overloading, lambda expressions, enums, constructors, and DateTime usage.

## Projects

- [Student Daily Report](SampleApplication.cs): A console application that collects a student's daily report information, including name, course, page number, help request, positive experiences, and study hours.
- [Anonymous Income Comparison](AnnualSalary.cs): A console application that asks for two people's hourly rates and weekly hours, calculates their annual salaries, and compares the results.
- [Anonymous Income Comparison App](AnnualSalaryApp): A second version of the annual salary comparison assignment using the same input, conversion, calculation, and comparison workflow.
- [Package Express](Delivery.cs): A shipping quote console application that checks package weight and dimensions before calculating a delivery estimate.
- [Driver Qualification](DriverApp.cs): A console application that determines whether a driver qualifies based on age, DUI history, and speeding ticket count.
- [Control Flow](Control-Flow.cs): A small assignment demonstrating `while` and `do while` loops with simple boolean conditions.
- [Arrays and Lists](Array.cs): A console application that lets the user select indexes from a string array, integer array, and string list while handling invalid indexes.
- [Six Part Assignment](6-Part-Assignment.cs): A multi-part assignment using arrays, loops, list searches, duplicate detection, break statements, and comparison operators.
- [Exception Handling](ExeptionHandling.cs): A console program that divides numbers from a list by user input and handles divide-by-zero and invalid-format exceptions.
- [Math Operations](MathOperations.cs): A class containing methods that double, triple, and add to an integer input.
- [Method Overloading](Calculations.cs): A class with overloaded calculator methods that accept an integer, string, or decimal and perform different math operations.
- [Void Method and Named Parameters](Method3.cs): A console program that calls a void method with two integer parameters, performs math on one value, and displays the other.
- [Optional Parameters](Mathematics.cs): A class with a method that accepts one required integer and one optional integer.
- [Optional Parameter Console App](Mathematics-OptionalParameter): A console application that lets the user enter one or two numbers and calls a method with an optional parameter.
- [Classes and Output Parameters](ClassSubmission): A class submission assignment demonstrating a void method, output parameters, method overloading, and a static utility class.
- [Methods and Objects](MethodsAndObjects): An object-oriented assignment that creates a `Person` base class, an `Employee` class, and a method for printing a full name.
- [Abstract Classes](Abstract-Classes): An inheritance assignment using an abstract `Person` class and an `Employee` class that overrides the `SayName` method.
- [Polymorphism](Polymorphism): An interface and polymorphism assignment where an `Employee` implements `IQuitable` and is referenced through the interface type.
- [Operator Overloading](OverloadedOperator): A class assignment that overloads the `==` and `!=` operators to compare employees by ID.
- [Lambda Expressions](LambaExpressions): A collection assignment that creates employees, filters for employees named Joe, and uses lambda expressions to filter by employee ID.
- [Parsing Enums](Program.cs): A console application that asks the user for a day of the week and parses the input into an enum with error handling.
- [DateTime](DateTime): A console application that prints the current time, asks the user for a number of hours, and displays the future time.
- [Constructor Chaining](Constructor-Chaining): A class assignment demonstrating constructor chaining with a `Person` object that stores a name and age.
- [Entity Framework Code First](EFCodeFirst): A .NET console application that uses Entity Framework Core with SQLite to create a database, add a student record, and save it through a `DbContext`.
- [Mathematics](Mathematics.cs): A method submission assignment that adds a required number to an optional second number.
